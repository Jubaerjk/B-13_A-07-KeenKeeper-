Project Name: Keen Keeper

Description: This is a website for keeping track of your friends interactions. You can add friends, edit their information, and keep track of your interactions with them.

Features:

- Add friends
- Edit friends information
- Keep track of interactions with friends
- View statistics about your interactions with friends
- View timeline of your interactions with friends

Used Technologies:

- Next.js
- React
- DaisyUI
- Tailwind CSS
- Chart.js
- JSON
